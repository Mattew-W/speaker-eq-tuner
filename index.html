1 测量

把设备音量调到常用档位，保持手机/麦克风与扬声器相对位置固定。录音电平偏小不影响频响——它只影响信噪比，够用就行。

测量前检查：杜比、DTS 与系统音效

浏览器无法读取这些开关。想测扬声器本身，请关闭空间音频、虚拟环绕、低音增强和音量均衡；想测日常听音链路，可保留音效，但测量、试听、验证时须保持相同模式和音量。动态音效与虚拟环绕不能靠单个麦克风位置准确校正。另外，输出电平 0 dB 是数字满幅：小喇叭在大音量下容易失真，失真会污染频响，听着明显破音就调到 −6 dB 以下。

测量端协同流程
  1. 电脑切到「播放端 · 电脑」，点「循环粉噪」或「循环扫频」持续播放测试信号。
  2. 手机放到实际听音位，点本页「开始采集（外部播放）」。
  3. 采集完成后照下方建议清单，在电脑端粘贴建议码导入 EQ。

本机不会发出测试信号；两端无需同时按键。扫频参数已固定为 5 s / 20 Hz–20 kHz。

使用说明与测量原理

一、操作流程

  1. 点击「开始测量」→ 浏览器会依次申请麦克风权限并启动音频引擎（须在用户手势中完成）。
  2. 把设备音量固定到日常使用档位，设备与麦克风相对位置保持不动，环境尽量安静。
  3. 测量完成后选择目标曲线，点「自动计算 EQ」，或直接手动增删/拖动频段。
  4. 用「试听（经 EQ）」确认听感，必要时微调；再点「二次测量验证」看修正后曲线是否更贴近目标。
  5. 「导出 JSON」保存参数，便于下次载入或在其他设备复用。

二、两种测量模式

  • 粉红噪声 RTA：持续播放粉红噪声，对采集信号做 Welch 分段 FFT 平均得到功率谱。无需播放/录制同步，收敛快、实现稳健，但抗环境噪声能力较弱。
  • 对数扫频（精密）：播放 20 Hz→20 kHz 指数扫频，用归一化互相关自动对齐播放与录制的时延，再做频域解卷积求脉冲响应；按「脉冲窗」截断后期房间反射，最后 FFT 得到准自由场频响。抗噪强、可抑制房间反射，推荐在安静环境使用。

三、必须了解的限制（重要）

  • 测量链路为「扬声器 → 空气/桌面反射 → 麦克风」的整体响应，包含麦克风自身频响与房间影响，不是经过校准的绝对频响。本工具做的是相对校正：先在 300 Hz–3 kHz 参考带内把实测曲线与目标曲线对齐，再对偏差求 EQ，因此不会因麦克风距离远而给出荒谬的整体增益。
  • 目标曲线（含 Harman 近似）为公开文献的近似参考形状，非官方精确数据；Harman 目标原本面向耳机/音箱在标准听音室的表现，直接套用于手机外放仅作听感参考。
  • 浏览器会默认开启回声消除(AEC)、自动增益(AGC)、噪声抑制(NS)，这些处理会严重破坏频响测量。本工具申请麦克风时显式关闭三者，但部分移动浏览器可能忽略该设置——界面会显示实际生效的约束值，请留意。
  • 手机外放与麦克风距离很近时，低频段易受机身振动与近场效应影响，建议 20–50 cm、设备平放于桌面、避开墙面。
  • iOS Safari：需关闭侧边「静音开关」，且页面首次交互后才能启动音频；请勿在后台标签页测量。
  • 请避免佩戴耳机测量——本工具测的是外放。

四、平台与权限

  • getUserMedia 仅在安全上下文可用：https:// 或 http://localhost。桌面端本地开发直接可用；手机通过局域网 IP 以 http 访问时麦克风会被浏览器拒绝，需将本应用部署到 HTTPS 站点后使用。
  • 所有音频处理均在本地浏览器内完成，不上传任何录音或文件。

五、双端协同模式（推荐用于外放测量）

  • 顶部可切换三种角色：一体式（本机自放自录）、测量端 · 手机（只录音分析、不发声）、播放端 · 电脑（只放信号与承载 EQ）。
  • 推荐流程：电脑切「播放端」→ 点「循环粉噪」或「循环扫频」持续播放 → 手机切「测量端」并放到实际听音位 → 点「开始采集（外部播放）」→ 手机算出 EQ 建议 → 复制建议码 → 电脑粘贴到「导入并应用 EQ」→ 试听。
  • 两端不需要同时按键、不需要网络对时：粉红噪声是稳态信号，采集窗口内任意时刻开始播放都不影响功率谱平均；扫频模式依靠互相关自动定位信号起点。因此信标采用循环播放，手机可随时开始采集。
  • 协同模式的信标参数在两端硬编码一致（扫频 5 s / 20 Hz–20 kHz / 间隔 1.5 s；粉噪 10 s 循环），请勿在两端改动扫频时长，否则解卷积参考信号失配。两端采样率不同不影响对齐。
  • 手机测的是「扬声器 → 房间 → 听音位 → 麦克风」的整体响应，仍属相对校正；目标曲线仅作听感参考，绝对精度受麦克风自身频响限制。

六、抗干扰（重复中值 · 噪声门控 · 可信度）

  • 空调声、说话声、通知提示音会污染测量，其中突发噪声最危险：它只在某一时刻注入能量，单次测量无法分辨是噪声还是扬声器在发声。
  • 重复 3 次 + 逐点中值：一次突发噪声只污染其中一次，中值天然把它排除；随机噪声的估计误差也随重复次数下降。
  • 先测 1 s 本底噪声：得到每个频点的信噪比。信噪比不足 20 dB 的频段判定为不可信，在图上以灰色区域标出，且不参与自动 EQ——否则算出的 EQ 是在补偿噪声而不是补偿设备。
  • 可信度色带：图表底部的细条颜色表示该频段可信程度，青绿为可信、灰色为不可信。
  • 代价是测量时间约 ×3。追求速度时可在「测量」面板取消勾选；环境安静时单次测量也已足够。
  • 无论是否开启抗干扰：关闭系统音效（杜比/DTS/空间音频）、通知静音、优先使用对数扫频而非粉红噪声，这几点对结果的影响比任何算法都大。
