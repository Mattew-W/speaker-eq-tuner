# Speaker EQ Tuner · 扬声器外放音质调校器

用浏览器给「设备外放声音曲线不佳」的问题做 EQ 微调：播放测试信号 → 麦克风采集实际外放声音 → 解算出频响曲线 → 与目标曲线对比 → 自动/手动生成参量 EQ → 实时试听与二次验证。

纯前端、零运行时依赖、所有音频处理在本机浏览器内完成，不上传任何录音。

---

## 功能

- **测试信号**：对数扫频（20 Hz–20 kHz）、粉红噪声、本地音频文件，全部经由参量 EQ 链播放。
- **采集与测量**：AudioWorklet 采集原始 PCM（不支持时回退 ScriptProcessorNode）；显式关闭 AEC / AGC / NS，并读取实际生效值。
- **两条测量路径**
  - 扫频：归一化互相关对齐 → 频域正则化解卷积 → 脉冲响应加窗 → 幅度谱。
  - 粉红噪声：Welch 法分段功率谱平均（Hann 窗，50% 重叠）。
- **目标曲线**：Flat、Harman 室内音箱（近似）、Harman 耳机 OE 2018（近似）、Warm、Vocal，另支持整体倾斜与低频补偿修饰。
- **自动 EQ**：先在 300–3000 Hz 参考带对齐消除整体电平差，对偏差做 1/6 倍频程平滑，贪心峰值拟合 + 增益最小二乘微调，输出 3–12 段参量 EQ。
- **手动微调**：图表上可拖拽的频段控制点（Pointer Events，触摸可用）、频率/增益/Q 滑杆、增删、启用、旁通、重置。
- **可视化**：对数频率轴 20 Hz–20 kHz、频响 / 偏差-EQ 双视图、HiDPI Canvas、实时电平表与采集过程频谱预览。
- **导出**：EQ 参数与全部曲线导出为 JSON。

## 两种使用模式

| 模式 | 适用 | 说明 |
|---|---|---|
| 一体式 | 单设备自测 | 同一台设备既播又录。简单，但扬声器与麦克风极近，机身耦合会让低频段失真。 |
| 双端协同 | 手机测、电脑调 | 手机只做采集分析，放到**实际听音位**；电脑循环播放标准信标并应用 EQ。两端不联网、无需对时，靠一段 `SEQ1\|...` 建议码人工传递。 |

双端协同之所以不需要同步时钟：粉红噪声是稳态信号，功率谱平均与起始时刻无关；扫频靠互相关自动定位起点，异步启动也能对齐。信标参数在两端硬编码一致（扫频 5 s + 1.5 s 静音间隔循环，粉噪 10 s 循环）。

## 快速开始

```bash
npm ci --registry=https://registry.npmjs.org/ --replace-registry-host=always
npm run manage   # 可视化启动、停止、构建与日志：http://127.0.0.1:4174/
npm run dev      # http://localhost:5173 ，同时监听局域网
npm run build    # 产物在 dist/
```

`npm run manage` 打开本机开发管理页，通过页面启动或停止开发服务、执行生产构建并查看日志。管理页只监听本机；它只能停止由自己启动的服务。关闭管理进程时，所启动的开发服务也会停止。云环境如需重装依赖，使用环境设置中保存的安装脚本，它将 npm 缓存放在可写目录。

需要 Node 18+。运行时零第三方依赖，`vite` 仅用于开发与构建。

## 使用步骤

1. 打开页面，点「启动音频引擎」（浏览器要求用户手势内初始化）。
2. 点「连接麦克风」，允许权限；确认权限胶囊显示的实际参数（AEC/AGC/NS 应为关闭）。
3. 把设备音量调到常用档位，保持麦克风与扬声器相对位置固定，环境安静。
4. 选择测量模式（扫频 / 粉噪）→「开始测量」。
5. 测量完成后选择目标曲线，点「自动计算 EQ」，或直接在图上拖点手动调。
6. 「试听（经 EQ）」对比听感；点「二次测量验证」确认校正后曲线是否更贴近目标。

## 重要限制

- **属相对校正，不是校准测量**。链路包含麦克风自身频响与房间反射，Harman 等目标曲线为近似参考形状，非官方精确数据。
- **移动端必须 HTTPS**。`getUserMedia` 仅在 `https://` 或 `http://localhost` 可用；用局域网 `http://192.168.x.x:5173` 访问时浏览器会拒绝麦克风权限。需要手机实测请部署为 HTTPS 站点。
- 参数 EQ 只作用于本页播放链，不会写入系统或硬件。想让改动全局生效，需把导出的参数抄进系统级 EQ（如 EqualizerAPO / Wavelet）。

## 技术栈

原生 ES Modules + Canvas 2D + Web Audio API（`AudioContext`、`BiquadFilterNode`、`AnalyserNode`、`AudioWorklet`）+ `getUserMedia`。FFT、窗函数、扫频生成、Welch PSD、解卷积、EQ 求解均为自实现，无第三方 DSP 库。

```
src/
├── contracts.js          模块契约与常量（频率轴、配色、EQ 边界）
├── main.js               状态机与 UI 装配
├── styles.css
├── core/
│   ├── dsp.js            FFT / 窗 / 扫频 / 粉噪 / Welch / 解卷积 / 平滑 / 映射
│   ├── targets.js        目标曲线定义与采样
│   ├── eq-solver.js      双二阶幅频响应 / 总响应 / 自动求解 / 残差
│   └── sync-code.js      双端协同建议码编解码
├── audio/
│   ├── engine.js         播放链、采集链、EQ 链重建、录音拼接
│   └── measurement.js     粉噪 / 扫频两种测量流程
└── ui/
    ├── chart.js          对数频率响应图、拖拽交互
    └── controls.js       EQ 频段编辑器
public/
└── capture-worklet.js    AudioWorklet 采集处理器
```
